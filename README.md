# FitMonth — программа похудения на месяц

Fullstack-приложение: **Next.js 15** (фронтенд, локально) + **Laravel 13** (бэкенд, Docker) + **Filament** (админка) + **Laravel Sanctum** (аутентификация) + **Laravel Horizon** (очереди).

Пользователь регистрируется по email и паролю, получает статус `pending` и ждёт одобрения администратора. Одобренный пользователь вводит рост, возраст и вес — ему формируется персональная 30-дневная программа здорового похудения с прогнозом веса. Первые 10 дней бесплатны (trial), дальше требуется подписка за **169 ₽** (демо-оплата). Без оплаты по истечении trial программа закрывается.

## Структура

```
fitmonth/
├── backend/            # Laravel 13 — запускается только через Docker
│   ├── docker-compose.yml   # nginx (:8000) · php-fpm · mysql · redis · horizon · scheduler
│   ├── Dockerfile
│   └── docker/              # entrypoint.sh, nginx.conf
├── frontend/           # Next.js 15 + TypeScript + Tailwind — запускается локально
└── README.md
```

## Требования

- Docker Desktop (включённый WSL2-бэкенд)
- Node.js 20+ (для фронтенда)

## Запуск бэкенда (Docker)

```bash
cd backend
docker compose up -d --build
```

При первом старте автоматически выполняются: `key:generate`, `migrate`, `db:seed`.

- API: <http://localhost:8000/api>
- Админка Filament: <http://localhost:8000/admin>
- Horizon: <http://localhost:8000/horizon> (только для администратора, остальным — 403)
- Healthcheck: <http://localhost:8000/up>

Полезные команды:

```bash
docker compose logs -f app        # логи PHP-FPM и миграций
docker compose exec app php artisan tinker
docker compose down               # остановить
docker compose down -v            # остановить и сбросить БД
```

## Запуск фронтенда (локально)

```bash
cd frontend
npm install
npm run dev
```

Откроется <http://localhost:3000>. Адрес API задаётся в `frontend/.env.local` (`NEXT_PUBLIC_API_URL`, по умолчанию `http://localhost:8000/api`).

## Как проверить сценарий целиком

1. Зарегистрируйтесь на <http://localhost:3000/register> — статус `pending`, приложение закрыто.
2. Войдите в админку <http://localhost:8000/admin> под `admin@example.com`.
3. **Пользователи** → фильтр по статусу «Ожидает модерации» → действие «Одобрить» (или bulk-«Одобрить»).
4. Обновите фронтенд: откроется форма ввода роста/возраста/веса → «Получить программу».
5. Дни 1–10 доступны, 11-й и дальше закрыты (paywall). Прогноз веса на 10 и 30 дней на главной программы.
6. «Оплатить 169 ₽» (демо) → открываются все 30 дней.

## Доступы и статусы

- Статусы пользователя: `pending → approved / rejected` (enum в `users.status`).
- Пароли хранятся **только в виде хэша** (cast `hashed` в модели `User`).
- Авторизация фронтенда — **Laravel Sanctum** (personal access tokens, `Authorization: Bearer …`).
- Админка Filament на `/admin`: `User::canAccessPanel()` возвращает `$this->admin` — обычные пользователи (даже одобренные) внутрь не попадают.
- Horizon на `/horizon` закрыт middleware `EnsureUserIsAdmin`: 403 для не-админов.

## Сущности (CRUD в админке)

- **Пользователи** — фильтр по статусу, действия «Одобрить»/«Отклонить» (включая массовые)
- **Профили** — рост, возраст, вес, пол, активность
- **Программы** и **дни программ** (RelationManager) — 30-дневный контент
- **Подписки** — trial/active/expired, даты, стоимость
- **Платежи** — сумма 16900 коп., статус, дата

Дашборд админки: статистика пользователей, выручка по подпискам, график регистраций за 14 дней, таблица ожидающих модерации.

## Бизнес-логика

- После одобрения пользователь вводит параметры → создаётся профиль и **trial-подписка на 10 дней**.
- Прогноз считается по формуле **Миффлина—Сан Жеора**: дефицит ≤ 400 ккал/день и ≤ 1% массы тела в неделю, калораж не ниже 1200 (Ж) / 1500 (М) ккал — «без вреда здоровью».
- Дни 11–30 возвращают **402 `SUBSCRIPTION_REQUIRED`** вне подписки. По истечении trial без оплаты закрываются все дни.
- Мок-оплата `POST /api/subscription/pay` создаёт платёж на 16900 коп. и открывает всю 30-дневную программу.
- Команда `subscriptions:expire` (по расписанию, container `scheduler`) помечает истёкшие подписки как `expired`; та же проверка выполняется «лениво» при каждом обращении.

## Основные эндпоинты API

| Метод | Путь                   | Описание                                    |
| ----- | ---------------------- | ------------------------------------------- |
| POST  | /api/register          | Регистрация (status = pending)              |
| POST  | /api/login             | Вход, возвращает Bearer-токен               |
| GET   | /api/me                | Пользователь, профиль, подписка             |
| POST  | /api/logout            | Выход (удаляет токен)                       |
| POST  | /api/profile           | Рост/возраст/вес/пол/активность → trial     |
| GET   | /api/program           | Прогресс, доступные дни, прогноз веса       |
| GET   | /api/program/day/{n}   | День программы (402 без подписки)           |
| POST  | /api/subscription/pay  | Демо-оплата 169 ₽ → доступна вся программа  |
